# Бот-магнит МенялоФФ (обмен USDT↔RUB)

Отдельный бот-воронка для продвижения основного обмена — кнопка "Обменять"
доступна с первого сообщения и на каждом экране, без обязательных шагов.

## Запуск (тот же способ, что и для карточного бота)

1. Создать нового бота через @BotFather → `/newbot`, получить токен.
2. GitHub: создать репозиторий, залить все файлы этой папки (Add file → Upload files).
3. Railway: New Project → Deploy from GitHub repo → выбрать репозиторий.
4. В Variables добавить:
   - `BOT_TOKEN` — токен от BotFather
   - `ADMIN_CHAT_ID` — ваш id от @userinfobot
   - `EXCHANGE_URL` — ссылка на основной бот обмена (по умолчанию уже стоит `https://t.me/USDT_X_RUB_BOT`, можно не менять)
5. Deploy.

## Логика воронки

/start → приветствие с 4 кнопками:
- 🚀 Обменять сейчас — сразу кнопка-ссылка на @USDT_X_RUB_BOT, без вопросов
- Купить USDT за рубли — показывает условия покупки + кнопка обмена
- Продать USDT за рубли — показывает условия продажи + кнопка обмена
- Не знаю, что нужно — позитивный экран-подсказка (без тревожных формулировок), в конце тоже кнопка обмена

Аварийный канал (кнопку можно добавить в любое сообщение через `trouble_menu` callback) —
три триггера: деньги не пришли, курс не совпал, перевод завис. Алерты падают в `ADMIN_CHAT_ID`.

## ⚠️ Обязательно докрутить перед стартом

В `texts.py` — `BUY_TEXT` и `SELL_TEXT` — сейчас плейсхолдеры `[TODO: ...]` для:
- реального курса/наценки
- процента комиссии
- мин/макс суммы операции

Впишите реальные цифры до того, как пускать трафик на бота.

## Админ-команда

`/breakage` — показывает соотношение аварий к переходам на обмен (из `ADMIN_CHAT_ID`).
